## 1. 美术总纲与视觉定位

### 1.1 一句话视觉定位

> **「等距战旗 + 中世纪暗色史诗 + 日漫二次元赛璐璐 + 源脉魔法的冷光」**

整个画面是一部被血与铁锈浸透的**暗色动画**：日漫二次元的**清晰线稿与赛璐璐平涂**构成人物与战场，唯有源脉魔法是其中偶尔刺出的、冷得发疼的蓝紫色闪电——暖色属于人间的火与血（日常、杀戮、苦难），冷色属于魔法的稀缺与代价（决战、救赎、毁灭）。这一组「**暖底冷锋**」的对比，就是「战争没有赢家，只有活下来的人」在视网膜上的直接落点。

> **风格与基调分工**：**画风 = 日漫二次元（赛璐璐）**；**基调 = 中世纪暗色史诗**（不变）。二次元 ≠ 明亮萌系——本作走的是**暗色系二次元（dark cel-shading）**，主题的沉重由色板（§2）与描线/质感符号化（§1.3）承载，而不是靠写实渲染。

### 1.2 三原则（引用 synergy-thematic-design 与 visual-player-guidance）

| # | 原则 | 一句话 | 反例（禁止） |
|---|------|--------|--------------|
| 1 | **主题优先（Thematic Primacy）** | 每个视觉元素都要回答「这如何服务『战争没有赢家』？」 | 为了「帅气」给角色加发光大剑、给魔法加粒子海——魔法必须冷、稀有、刺眼，不能像 fireworks |
| 2 | **风格统一（Style Coherence）** | 全部元素同一渲染语言：**日漫二次元·赛璐璐（Anime cel-shading）**——清晰线稿 + 平涂 + 硬边阴影；禁止混入写实厚涂 / 照片写实 / 3D 写实渲染 / 萌系 Q 版 | UI 用赛璐璐、单位用写实厚涂、背景用 3D 渲染——这会让游戏看起来像素材库拼贴 |
| 3 | **魔法稀缺可视化（Magical Scarcity Visibility）** | 魔法光源永远**冷色、稀有、刺眼**，区别于暖色日常光（火把、篝火、晨光） | 让「火球术」用暖橙色——火球应是**冷蓝核心 + 边缘余烬**，强调它是被强行扯出来的源脉之力，不是普通的火 |

> 三原则自检：任何一张外包稿件，对照这三条逐项打勾才能过审（见 §12 验收清单）。

### 1.3 整体风格定调

**日漫二次元 · 赛璐璐（Japanese anime style, cel-shading）**——以「**清晰线稿 + 平涂色块 + 硬边二级阴影**」为唯一渲染语言，气质**暗色、克制、写给成年玩家的二次元**（不萌、不幼、不 Q）。

- **线条 Lineart**：所有元素都有**清晰线稿**（动画风描边 1.5-2.5px，重要结构 / 暗部分线加粗到 3px）；线色用**暗调色线**（`#1A1A24` 或材质同色的深阶——金属线用铁灰暗阶、皮肤线用褐调深阶、布料线用同色加深），**禁止**纯黑死线。**禁止**无线稿的大色块堆叠、**禁止**写实油画式笔触
- **上色 Shading**：赛璐璐平涂 + **硬边二级阴影**（基底 / 影 / 高光三阶，细则见 §2.5 色阶规范）；阴影边界是**锐利色块分界**（允许 1px 软边过渡），**禁止**大面积柔光渐变与空气刷糊面
- **造型 Proportion**：角色按二次元比例（头身比 6.5-7.5，面部简化，**眼睛是情绪主通道**，头发成束分组）；装备适度夸张（肩甲 / 披风 / 武器放大 10-15%），保证 48×48 等距小尺寸下剪影可辨（对齐 §5.3）
- **质感 Texture**：金属有锈迹与划痕、布料有磨损与补丁、皮肤有污渍与伤疤——一律用**线稿 + 色块符号化**表达（破口线、缝补线、污渍点、掉漆色块），**禁止**照片级纹理贴图与毛孔级细节
- **光影 Lighting**：单一主光源（西北 45° 高角度阳光，冷白），**硬边投影**；允许动画式**边缘光（rim light）**与**形状化高光**（金属棱边「一字高光」、发梢碗形高光、眼睛双点高光）；**禁止**电影级 HDRI 多光源、**禁止**过饱和霓虹

**生图 / 外包风格关键词（英文，拼进 prompt 用）**：

```
Japanese anime style, 2D cel shading, clean crisp lineart (colored line trace, no pure black),
flat base colors with hard-edged 2-tone shadows, stylized anime proportions, expressive eyes,
dark fantasy medieval tone, desaturated grim palette, war-worn details rendered as line-art
damage marks and flat stains, single hard-edged light source, readable silhouette.
NEGATIVE: photorealistic, oil painting, impasto brush strokes, soft airbrush gradients,
3D render, pixel art, chibi, moe, oversaturated neon.
```

### 2.5 赛璐璐色阶规范（二次元落地细则）

> 二次元 ≠ 换色板：§2.1-§2.4 的色板**全部保留**（暗色史诗基调不变），变的是**用色阶数**——每个材质用**三阶色块**表达，而不是连续渐变。

| 阶 | 定义 | 推导规则 | 例（铁灰板甲） |
|----|------|----------|----------------|
| **基底 Base** | 材质本色（§2.1/§2.2 色板原值） | 直接用色板色 | `#4A4A4A` 铁灰 |
| **影 Shadow** | 单一硬边暗阶 | 基底 **→ 向夜墨 `#1A1A24` 压暗 25-40% + 轻微冷偏（+蓝紫）** | `#2B2B3A` 铁灰暗面 |
| **高光 Highlight** | 形状化亮阶（非渐变） | 基底 **→ 提亮 20-35% + 冷白偏移**（金属可叠 1px 骨白棱线） | `#6B7B8C` 钢蓝高光 |

- **阴影统一冷偏**：所有材质的影阶都要比基底**更冷**（向铁灰/夜墨/源晶紫方向偏）——这是「冷锋」基调在赛璐璐里的落点，也让暗色画面在二次元语言下依然压抑
- **线色规则（色线）**：描边线用**材质同色深阶**或统一 `#1A1A24`；皮肤 / 布料线可分别用褐调 / 同色深阶，**禁止**纯黑 `#000000`
- **三阶 + 例外**：小尺寸资产（48×48 sprite、16×16 缩略图标）允许**退到二阶**（基底 + 影，高光只留 1-2 个点），保证可读性优先（对齐 §5.2）
- **情绪例外**：§2.4 的结局 / 章节情绪色板同样按三阶落地（如「死寂蓝灰 `#3D4A5C`」需要有 `#252C38` 影阶与 `#6E7F92` 高光阶）

## 3. 等距渲染规范（核心技术约束）

> **本节是给像素美术、3D 美术、技术美术的硬规范。** 所有数字来自 `iso_coords.gd` / `block_metrics.gd` / `unit_sprite.gd`，违反则资源在引擎中错位。

### 3.1 等距视角参数（以代码为准）

| 参数 | 值 | 来源 |
|------|-----|------|
| 投影模式 | 正交（Orthographic），**无透视畸变** | `iso_coords.gd::setup_ortho_camera` |
| 相机旋转 | **俯角 30°（X 轴 -30°）+ 偏航 45°（Y 轴 45°）** | `iso_coords.gd` L53 `cam.rotation_degrees = Vector3(-30, 45, 0)` |
| cell 世界尺寸 | `CELL = 1.0` 单位 | `iso_coords.gd` L19 |
| 屏幕投影 | 方形 cell 在屏幕上呈 **2:1 菱形**（宽:高 = 2:1） | `iso_coords.gd` 头注释 |
| 分辨率 | 1280×720，stretch mode `canvas_items` | `project.godot` |

> **重要更正**：任务文档提到「35.264° 等轴测」是通用等距标准，但**本项目代码实际用 30°**（因原素材是 128×64 的 2:1 菱形，30° 俯角才能让方形投影成 2:1）。所有美术产出必须按 **30° 俯角 + 45° 偏航**的视角绘制。

#### 等距视角参考立方体（美术起手模板）

```
            ┌─┐
           ╱  ╱│   ← 顶面（菱形，最亮，主光来自西北 45°）
          ┌─┐ │
          │  │ ┤   ← 右侧面（中调，受反射光）
          │  │╱
          └─┘     ← 左侧面（最暗，背光）

   像素比例：顶面菱形 128×64，左右面各 64×64（高）
   光照：顶面 100% 明度 / 右面 70% / 左面 45%
```

### 3.2 block（地形 tile）规范

> block 是地图的最小视觉单元，对应 `block_metrics.gd` 的扫描逻辑。

| 维度 | 规范 | 说明 |
|------|------|------|
| **画布尺寸** | 推荐 **128×128 px PNG**（菱形 128×64 居中，上下各留 32px 给高出菱形的建筑） | 现有 blocks 画布不一（138/170/172/174），但**内容菱形**必须 128×64 |
| **内容菱形** | **严格 128×64**（DIAMOND_W × DIAMOND_H），见下方示意 | `block_metrics.gd` 扫 alpha 求内容边界，内容超菱形会错位 |
| **背景** | **完全透明** PNG（菱形外 alpha=0） | `block_metrics.gd` 用 alpha>0.06 判定内容 |
| **可超出** | 建筑/树/装饰可**向上**超出菱形（origin_offset 把内容底部菱形顶点对齐 cell 中心） | 如树高、塔尖、山峰 |
| **不可超出** | **水平方向不得超出菱形左右顶点** | 会侵入相邻 cell，破坏网格 |
| **像素密度** | 1 cell = 128px 菱形；建筑细节允许 2x（256px）/3x（384px）超采样后缩到 128 | 保留高模细节 |

### 3.4 相机、比例与光照

| 项 | 规范 |
|----|------|
| **相机** | 正交，俯角 30°，偏航 45°，无透视畸变 |
| **主光源** | 西北 45° 高角度方向光（DirectionalLight3D），冷白色（色温 ~6500K，`#E8EEF5`），强度中等 |
| **环境光** | 偏冷蓝（`#3D4A5C`），低强度，填充阴影 |
| **单位阴影** | **关闭**（billboard 不接收阴影，保证小尺寸可读性） |
| **建筑阴影** | 可有投影（投射到地面菱形上，方向与主光一致，西北→东南） |
| **二次元渲染（赛璐璐化）** | 3D 部分（地面 block / 建筑）用**赛璐璐化着色**：光照只取 **2-3 阶硬边色阶**（shading ramp 无平滑过渡）、可选材质描边；与单位 sprite 的手绘线稿风格对齐。**禁止** PBR 写实高光、柔和 GI 渐变、环境光遮蔽糊面 |
| **描线对齐** | 单位 sprite / 建筑 / block 的描边粗细按同一档（1.5-2.5px，§1.3），避免单位像「贴纸」浮在场景上 |
| **后处理** | 轻微 vignette（暗角），轻微 color grading（降饱和 10-15%，强调暗色史诗感）；**不做**写实胶片颗粒 / 镜头光晕 |

## 9. 特效（VFX）规范

### 9.1 魔法特效（按元素，对齐 [07 技能](07_skills.md) 的 6 元素）

> **核心原则**：所有魔法特效必须**冷光稀有**，区别于暖色日常光（火把、篝火）。即使是火元素，核心也是冷蓝、边缘才是余烬橙。
>
> **二次元技法（渲染语言）**：特效一律用**动画式 2D 特效语言**——赛璐璐色块、拖影（残像 2-3 帧）、单帧白闪（impact frame）、速度线、形状化光斑；**禁止**写实粒子海 / 体积光 / 照片级辉光（既破坏赛璐璐的统一渲染语言，也稀释「魔法稀缺」）。

| 元素 | 施法前摇 | 命中爆发 | 色彩 | 稀有感 |
|------|----------|----------|------|--------|
| **fire 火** | 杖尖凝出冷蓝核心光球 | 冷蓝核心炸开 + 边缘余烬橙 `#C4631F` 飞溅 | 冷蓝 `#7FDBFF` 核心 + 余烬橙边缘 | 强调"被强行扯出的源脉之火"，不是普通火 |
| **water 水** | 空气凝结霜雾 | 冰晶碎裂 + 寒气扩散 | 冰青 `#A8C8E0` | 罕见的寒流，刺骨 |
| **earth 地** | 地面浮现源脉紫裂纹 | 石笋从裂纹中突刺 + 紫尘 | 源脉紫 `#7B4FC8` + 岩褐 | 大地被源脉驱使的暴力 |
| **wind 风** | 气流扭曲（heat shimmer） | 青色风刃切割 + 撕裂声 | 风青 `#5A7A8C` | 无形的利刃 |
| **light 光** | 圣金符文在空中显现 | 金光炸开 + 净化纹路 | 圣金 `#D4AF37` + 白 `#F5E6D3` | 神圣但刺眼，维兰瑟专精 |

## 10. 动画规范

### 10.1 帧率（对齐 `profession_visual.gd::build_idle_frames` 的 `set_animation_speed`）

| 动作 | 帧率 | 理由 |
|------|------|------|
| idle 待机 | **8 fps** | 缓慢呼吸感，不抢注意力（对齐 knight idle 现有速度） |
| move 移动 | 10 fps | 中速，循环脚步 |
| attack 攻击 | **12 fps** | 1 秒挥击，关键发力帧在 6-8 帧 |
| hit 受击 | **16 fps** | 快速冲击，0.25s 完成 |
| die 死亡 | 12 fps | 倒下 + 淡出，0.4s 完成 |
| cast 施法 | 10 fps | 前摇 0.5s（5 帧）+ 释放 0.5s（5 帧） |

### 10.2 循环接缝

- **idle / move 必须无缝循环**：第 F0 帧与第 F7 帧的姿态差异 < 5%（肉眼不可见）
- **attack / hit / die 不循环**：单次播放后停留最后一帧（die 停在倒地）

### 10.3 关键帧 pose（每个动作的骨架）

```
   idle（8 帧，循环）：
     F0: 中性站立（重心平衡）
     F1-F3: 微微吸气（胸廓前抬 2px）
     F4: 顶点（最高吸气）
     F5-F7: 微微呼气（回到 F0）
     ↑ 武器保持静止，仅躯干微动（避免抢戏）

   attack（12 帧，单次）：
     F0-F1: 起手（武器从静止抬起）
     F2-F3: 蓄力（武器后拉到最远）
     F4: 发力前瞬（最紧绷）
     F5-F8: 挥击（武器沿弧线快速划过，残影）
     F9: 命中帧（武器接触目标，最大延伸）
     F10-F11: 收招（武器回到 F0）

   hit（4 帧，单次）：
     F0: 正常站立
     F1: 后仰（躯干后倾 10°）
     F2: 闪白（全白 1 帧强调冲击）
     F3: 回弹（回到 F0 或转 die）

   die（5 帧，单次）：
     F0: 正常
     F1: 膝盖弯曲
     F2: 单膝跪地
     F3: 倒地（侧卧）
     F4: 开始淡出（alpha 80%）
     （后续 0.5s 引擎补间 alpha → 0）
```

### 10.4 动画表演原则（二次元）

> 帧率与帧数不变（§10.1，对齐 `profession_visual.gd`）；下面 5 条是让 48×48 sprite **读起来像动画而不是木偶**的表演规则（动漫作画原则）。

| 原则 | 落地（以 attack 12 帧为例） |
|------|------------------------------|
| **预备动作 Anticipation** | 发力前先反向蓄力（武器后拉 2 帧），给玩家「要打了」的预告（对齐 §10.3 F2-F3） |
| **顿帧（「间」）** | 发力前 1 帧**完全静止（hold）**，随后 1-2 帧快速划过——快慢对比出速度感 |
| **跟随与延迟 Follow-through** | 头发 / 披风 / 披肩**比身体延迟 1-2 帧**运动，收招时再回弹 |
| **轻度夸张 Exaggeration** | 挤压拉伸 ≤5%（呼吸 2px、冲刺拉长 1px），**只作用姿态不作用结构**（脸不能变形） |
| **速度线 / 残像** | 只在攻击命中帧附近出现（残像 2-3 帧、速度线 1 帧），**禁止**全动作常驻（会廉价化） |

> 二次元专项：**眼睛高光与眉形随情绪变化**（受击时眉压低、蓄力时高光收窄）——48×48 下这是唯一能读出情绪的两三个像素。

## 12. 美术产出流程与验收清单

### 12.1 产出流程（概念图 → 线稿 → 上色 → 最终）

```
   [1] 概念图（Concept，3 张草图选 1）
        ↓  主题自检（§1.2 三原则）
   [2] 线稿（Lineart，确认剪影辨识度 + 面部 / 发型分组）
        ↓  剪影测试（去色后能否认出职业/角色？）
   [3] 上色（Color，赛璐璐三阶色 + 国别色板对齐）
        ↓  色板自检（§2 四国色板 / §2.5 色阶是否准确？）
   [4] 最终（Final，确认尺寸/格式/命名）
        ↓  技术自检（§3 尺寸规范是否达标？）
   [5] 入库（命名 + 路径 + 版本）
```

### 12.2 通用验收清单（每张图过审必填）

| 检查项 | 是 / 否 |
|--------|---------|
| ☐ 1. **主题一致**：这张图服务「战争没有赢家」吗？魔法是否冷光稀有？ | |
| ☐ 2. **风格统一**：是否**日漫二次元赛璐璐**（清晰线稿 + 平涂 + 硬边二级阴影），无写实厚涂 / 照片写实 / 像素混用？ | |
| ☐ 3. **色阶规范**：是否三阶色（§2.5）？阴影是否冷偏？线色是否非纯黑？ | |
| ☐ 4. **尺寸规范**：block 菱形 128×64？立绘 512×512？sprite 48×48 ×N？ | |
| ☐ 5. **国别色板**：角色/单位/建筑的颜色对齐 §2.2 四国色板了吗？ | |
| ☐ 6. **剪影辨识**：去色后能否 0.1 秒认出这是什么职业/角色？ | |
| ☐ 7. **命名规范**：路径与命名对齐 §11.1 了吗？ | |
| ☐ 8. **透明背景**：block/sprite/icon/portrait 是否 PNG 透明背景？ | |
| ☐ 9. **无禁用元素**：无火药/蒸汽机？无写实厚涂笔触？无萌系幼态 / 过饱和亮色？（精灵族已纳入，不在禁用之列） | |

### 12.3 外包 brief 模板要点

每份外包 brief 必含：

1. **资源名 + 路径**（如 `char-kael.png` → `res://assets/ui/portraits/char-kael.png`）
2. **尺寸 + 格式**（512×512 PNG，透明背景）
3. **本文件章节引用**（如"对齐 §6.1 凯尔 spec 卡"）
4. **色板**（精确 HEX，给色块图）
5. **参考图**（§1.4 的参考游戏/画师 mood board）+ **风格关键词串**（§1.3 生图关键词，直接抄进 prompt）
6. **剪影测试要求**（提交时附去色剪影图）
7. **禁止清单**（无火药/蒸汽机、无写实厚涂/照片写实、无 3D 写实渲染、无萌系幼态/过饱和、无纯黑死线）（精灵族已纳入美术，不在禁用之列；精灵相关外包需另附精灵规范 brief）
8. **交付期限 + 修订轮次**（建议 3 轮：概念/线稿/最终）

### 12.4 风格漂移检测

每月抽 5 张不同作者的资源，做"**风格一致性盲测**"：
- 把 5 张图放一起，请未参与的人辨认"是否同一游戏？"
- 若任一张被认出"风格不同"，触发该作者的 style refresh 回炉
