# 世界观设定（Worldview）

> 本文档对应设计支柱 **「抉择」** 与世界基调约束，为所有后续文档（[国家设定](02_nations.md)、职业、剧情、道具）提供统一的地理、历史、魔法、信仰基底。一切设计须服从 `00_design_pillars.md` 中的「**二元魔法（普通魔法普及 / 神级魔法稀缺）**」与「**战争没有赢家**」两大硬约束（参考：synergy-thematic-design 主题协同）。

---

## 一、世界名与一句话定位

- **世界名**：**艾尔迦德（Eregaard）**
- **一句话定位**：一片普通魔法普及、却被远古「源脉秘法卷轴」的传说撕裂的大陆——诸国为争夺那能单方面碾压他国、打破平衡的**神级秘法**彼此厮杀，而每一卷卷轴的现世，都把世界推向又一次大碎裂。

> 主题协同约束（参考：synergy-thematic-design）：本世界的所有地理、历史、信仰设定都必须服务于「**战争没有赢家，只有活下来的人**」这一中心命题。胜利的代价、资源的透支、信念的崩塌，是世界观的底层逻辑，而非装饰。

## 二、地理总览

### 大陆结构

艾尔迦德大陆（the Eregaard Continent）由一块主大陆与三处边缘群岛组成。大陆中央纵贯一条巨型山脉，将世界天然切成「东、西、北」三大政治板块，这也是三国鼎立格局的地理根源。

| 地形区 | 名称 | 位置 | 战旗地形映射 | 战略意义 |
|--------|------|------|--------------|----------|
| 中央山脉 | **苍脊山脉（Argent Range）** | 大陆纵轴 | 山地 / 隘口 / 高地 | 阻断东西，唯一的几处隘口是兵家必争 |
| 第一长河 | **银泪河（Silver Tear）** | 发源苍脊西麓，西南入海 | 河流 / 浅滩 / 桥 | 农业命脉，水运贸易动脉 |
| 内陆沙漠 | **烬海（Ashen Sea）** | 大陆东南 | 沙漠 / 荒地 / 沙暴区 | 古源脉干涸之地，魔法废墟密集 |
| 北方冻原 | **霜落荒原（Frostfall）** | 大陆北缘 | 雪地 / 冰原 / 密林 | 蛮族与异端信仰盘踞地 |
| 西方海域 | **碎月湾（Broken Moon Bay）** | 大陆西海岸 | 海岸 / 浅滩 / 岛屿 | 海贸枢纽，城邦联邦发家地 |
| 地下溶洞网 | **回声深渊（Echoing Deep）** | 苍脊山脉之下 | 洞穴 / 地下城 / 熔岩 | 矮人故土，源脉离地表最近处 |

### 气候带（自南向北）

1. **南方热带季风**——银泪河三角洲，粮仓，湿热，多雨林沼泽
2. **中部温带**——苍脊两麓平原，文明核心，四季分明
3. **北方亚寒带**——霜落荒原，长冬短夏，针叶林
4. **东南干旱带**——烬海，极度干燥，昼夜温差极大

> 地形直接映射战旗地图 tile 类型：山地（def+ / mov-）、河流（mov 大幅下降 / 骑兵不可趟）、森林（回避+ / 防-）、沙漠（mov- / 无掩蔽）、雪原（每回合 HP 微损）、洞穴（视野- / 魔法伤害+）。这些为后续 `professions.json` 中 `moveType: foot/ride/fly` 的设计提供依据。

## 三、历史纪元

艾尔迦德有据可考的历史分为四个纪元。当前处于**第四纪元的末期**——一个旧秩序崩塌、新战争将起的黄昏。

### 第一纪元：源启纪（Age of Origin）—— 远古
神级魔法（源脉之力）如江河般奔涌，源脉尚未沉入地下，神祇般的「源脉编织者」直接以意志改写山河——他们能施放今日被称为「神级秘法」的天灾级法术。这一纪元没有国家，只有一座座以源脉为基的「源城」。编织者们最终因内战而引发**「大碎裂」**，源脉被撕断、沉入地底，编织者一族近乎灭绝。**普通魔法（元素之力）在这一纪元已存在，但被视为下乘技艺。**

> 遗存：遍布烬海的源城废墟、苍脊之下的回声深渊、少数血脉中残存的「源裔」天赋、以及编织者临终前将秘法「写入」的极少数**神级秘法卷轴**（全大陆已知个位数，是第四纪元各国争夺的焦点）。

### 第二纪元：沉寂纪（Age of Silence）—— 大灾变后
大碎裂后，**神级魔法（源脉之力）几近断绝**，但**普通魔法（元素之力）从未消失**——它在民间以巫术、占星、草药魔法的形式延续。人类在废墟上重建农耕文明，这是一个长达千年的黑暗中世纪，文字散佚，城邦林立，战乱频仍。**对源脉编织者的崇拜与恐惧在这一纪元定型**：有人奉他们为神，有人视他们为必须永镇地底的恶魔。

> 遗存：对源脉秘法的禁忌记忆、流亡的源裔血脉、神级秘法卷轴在乱世中辗转藏匿。

### 第三纪元：诸国纪（Age of Kingdoms）—— 国家成型
随着普通魔法的系统化（学院化的元素引导术）与对源脉的重新发现，**普通法师成为各国常规兵种，而极少数源裔则尝试重新承载神级魔法**——但必须借助残存的神级秘法卷轴。王国、帝国、神权国相继崛起。**神级秘法卷轴的稀缺性在这一纪元被彻底确立**：卷轴不可复制、不可抄录，谁持有一卷便握有碾压他国的可能——这埋下了第四纪元争霸的祸根。

> 遗存：当代各国的版图与政体，皆成型于此纪元。各国对卷轴的暗中搜集由此开始。

### 第四纪元：黄昏纪（Age of Dusk）—— 当下（争霸时代）
数卷被认为已佚失的神级秘法卷轴接连「现世」，传闻其一藏于苍脊山脉中段的**「圣城艾尔萨」**。**好战国君主为求速胜甚至与恶魔交易，主动出击搜刮卷轴；神权国以「净化异端」为名暗搜卷轴、屠戮精灵取水晶**；其余各国为不被碾压而被迫卷入。同时，一场被称为**「灰潮」**的怪异瘟疫从烬海向北蔓延——被感染者的血液会逐渐石化，而石化的核心，正是历代神级魔法滥用反噬所凝结的源脉碎片。

> 当前时间线：灰潮爆发第三年，数卷神级秘法卷轴的归属争夺白热化前夕。这正是游戏开战的时刻，也是 [国家设定](02_nations.md) 中各国的初始状态。

## 四、魔法体系：普通魔法 + 神级魔法（二元结构）

> **这是本世界观的核心设定，必须自洽。** 一切职业、技能、道具的魔法属性都必须经得起本节的推演。直接对齐 `00_design_pillars.md` 第五节「二元魔法硬约束」。

### 4.1 普通魔法（普及资源）

- 普通魔法源于**元素之力**——天地间自然流转的火 / 水 / 土 / 风 / 光 / 暗六系能量，**与源脉无关**。任何具有**魔法血脉天赋**的人都可引导。
- 法师（magic 类职业）是各国军队的**常规兵种**，与剑士 / 弓手 / 骑士并列，不再是「万中无一的王牌」。各国民间亦有术士、巫医、占星师等泛魔法职业。
- 每次施法消耗 **MP（法力）**，MP **可常规回复**：营地休息回满、战后整备回满、常规药剂补充。MP 经济从「不可回满的硬底线」放宽为「常规资源管理」（具体池量与回复曲线待 [11 平衡](11_balance_and_progression.md) 重算）。
- 普通魔法的策略性来自**元素克制循环**（fire→wind→earth→water→fire，×1.5）与**射程 / MP 预算**，而非来自稀缺。
- **精灵族**天生元素亲和极强（见 5. 种族表），是普通魔法的天然高手，因此被人族忌惮（见精灵族条目）。

> 设计映射：普通魔法对应 `skills.json` 常规 mpCost 技能，法师职业占比上调、MP 池放宽。详见 [03 职业](03_professions.md) ⚠ 待重写。

### 4.2 神级魔法与卷轴体系（古代源脉秘法 · 极稀缺 · 国家争夺焦点）

> 这是本作「战争没有赢家」主题与「抉择」支柱在新设定下的核心落点，也是 [02 国家](02_nations.md) 冲突的根本动因。

#### 4.2.1 本源：源脉（Ley Lines）

- 神级魔法源于地底深处的**「源脉」**——第一纪元大碎裂时，源脉编织者的躯体与意志崩解后，化作无数条在大地之下缓缓流淌的**神级魔力**之河。
- **重要修订**：源脉**只承载神级魔法**，与普通魔法无关。普通魔法走元素之力，不经源脉。
- 源脉在地表有若干涌出点，称**「源井」（Ley Wells）**。源井可被开采，但**不可再生**——一口源井被抽干便永久枯竭，连带周边土地一同死去（灰潮成因之一）。
- 源脉总量自大碎裂以来单调递减，**「用一点，少一点」**是神级魔法的铁律。

#### 4.2.2 载体：秘法卷轴（Sacred Scrolls）

- 神级秘法以**卷轴**形式传承——这是古代编织者将自身源脉秘法「写入」的固态载体，是全大陆最稀缺的物件，**已知存世个位数**。
- 习得神级魔法必须**同时满足**两重门槛：
  1. **卷轴**：必须**夺取 / 继承**一卷秘法卷轴（卷轴不可复制、不可抄录，毁一卷少一卷）；
  2. **源裔**：施法者必须是**源裔**（体内残存第一纪元编织者血脉者），才有承载神级魔法的生理基础。
- 二者缺一不可——卷轴无源裔是死物，源裔无卷轴只能用普通魔法。

#### 4.2.3 战略意义：打破国力平衡

> **核心命题**：拥有神级秘法的国家，能**单方面碾压其他国家、打破大陆平衡**。

- 一国持有一卷神级秘法，相当于获得「天灾级」战略武器：一记神级法术可摧毁一座要塞、一支军团、甚至改变一地地貌。
- 这是 [02 国家](02_nations.md) 之间冲突的**真正核心**——战争不是为了争夺领土或源井，而是为了**夺取 / 阻止他国夺取神级秘法卷轴**。谁集齐卷轴，谁就能以一国之力的碾压之势终结乱世——也可能在滥用中把世界推向第二次大碎裂。
- 因此：神级秘法卷轴的**现世、易主、争夺**，是主线剧情的总发动机（见 [05 剧情](05_story_branches.md) 与 [02 导火索](02_nations.md#6-主冲突导火索)）。

#### 4.2.4 施法代价（三重，神级魔法专属）

神级魔法每次施法都有**三重代价**，普通魔法只有 MP 代价一项：

| 代价类型 | 表现 | 战旗数值映射 |
|----------|------|--------------|
| **MP 代价** | 消耗源晶介质的 MP（神级魔法 mpCost 极高） | `skills.json` 奥义 / 卷轴技能 mpCost，需源晶 / 源井回复 |
| **血肉代价** | 过度引导源脉令施法者肢体逐渐石化（灰潮的微缩版） | 源裔施法者 HP 上限随累计施法次数缓慢下降，或施法自伤 |
| **大地代价** | 抽取源脉加速当地源井枯竭，枯竭区灰潮蔓延 | 剧情层：神级魔法用越多，地图环境越荒芜（环境叙事） |

> 三重代价确保神级魔法不会被滥用——每一记神级法术都是一次战略抉择。这直接服务「抉择」支柱与「神级魔法稀缺」约束（参考：synergy-thematic-design 主题协同）。

#### 4.2.5 代表性神级秘法卷轴

> 以下为代表性卷轴，对接 `skills.json` 奥义槽与 `items.json` 卷轴类道具。具体数值与获取路径（城池 / 宝藏 / boss 掉落）、习得机制、字段定义见 [06 道具](06_items.md) 与 [07 技能](07_skills.md)。

| 卷轴 id（暂定） | 名称 | 元素 | 效果（战略级） | 代价 |
|------------------|------|------|----------------|------|
| `scroll_cataclysm` | **天崩卷轴** | 土 | 范围毁灭性地动，摧毁一片战场与建筑 | mpCost 极高 + 施法者石化 -1 HP 上限 |
| `scroll_searingFirmament` | **焚天卷轴** | 火 | 召唤天火焚城，持续数回合灼烧 | mpCost 极高 + 当地源井加速枯竭 |
| `scroll_severance` | **断脉卷轴** | 暗 | 永久切断目标区域与源脉的联系（灭一国之魔法根基） | mpCost 极高 + 施法者永久失明 |
| `scroll_genesis` | **创世卷轴** | 光 | 传说级复苏术，可复活 / 净化灰潮（全大陆唯一能逆转灰潮之物） | mpCost 极高 + 施法者以命献祭 |

### 4.3 谁能用魔法（双层门槛）

#### 普通魔法（普及）
- 门槛：**魔法血脉天赋**（人群中约 10-20% 具有不同程度的魔法天赋，门槛低）。
- 精灵族天赋最高，人类次之，岩族 / 烬民偏弱。
- 因此法师是常规兵种，各国军队均有成建制法师团。

#### 神级魔法（极稀缺）
- 门槛：**源裔血脉 + 卷轴**，双重条件缺一不可。
- **源裔（Ley-born）**：体内残存第一纪元编织者血脉者，约占人口万分之一（**人类与精灵中皆有源裔，精灵源裔比例反而更高**）。只有源裔有承载神级魔法的生理基础。
- **启悟（Awakening）**：源裔须在源井旁经历一次濒死级的「启悟仪式」，绝大多数源裔在仪式中疯癫或死亡，存活率不足一成。
- **卷轴**：即便通过启悟，无卷轴也无法施神级魔法。卷轴是真正的稀缺瓶颈。
- **誓缚者（Oath-bound）**：极少数通过启悟且持有 / 被授予卷轴的源裔，会被国家以血誓绑定服役，成为各国**最稀缺的终极战略资产**——一名神级法师的价值等同于一国国运。

> 因此：神级法师（卷轴持有者）在各国都是个位数到零的存在，且卷轴不可复制——这与战旗「神级魔法单位极强但极稀、阵亡不可复活、卷轴不可再生」的设计契合（参考：synergy-thematic-design）。

## 五、种族 / 民族

> 不堆砌。每个种族必须有明确的叙事理由与玩法区分，而非装饰（参考：game-development-planning 约束三角——砍范围，宁少勿滥）。源裔为「人类 / 精灵中可承载神级魔法的血脉亚种」。

| 种族 | 人口占比 | 叙事存在的理由 | 玩法/职业映射 |
|------|----------|----------------|---------------|
| **人类（Men）** | 约 85% | 世界主体，诸国的建立者。短命、繁殖快、野心重，是神级秘法争夺的主要推手，也是战争的主要受害者。 | 全部基础职业：剑/枪/斧/弓/骑/法（普通魔法） |
| **精灵族（Elves）** | 约 3%（不常见） | **天生元素魔法天赋极强**，额头正中有一枚**魔法水晶**（魔力核心，**失去水晶精灵便会衰竭而亡**）。寿命长、容貌俊美、亲和自然。因人族恐惧精灵以魔法天赋颠覆人类政权，**长期被人族奴役倒卖**：有的沦为战争工具（法师奴隶兵），有的沦为劳动力，有的落入风俗业。**神权国尤其视精灵为异端**，以「精灵是魔法的偷窃者」为名公开诛杀——真实目的是**夺取精灵额头的魔法水晶**（水晶可用于神级魔法介质 / 强化源裔承载力）。精灵中亦有源裔，是各国秘法争夺的「人形矿藏」。 | 普通魔法系职业的天花板（mage / sage 倾向），高 res / 高魔法成长；支线「精灵解放」可获强力精灵同伴 |
| **岩族（Stoneborn，矮人变体）** | 约 5%，聚居回声深渊 | 第一纪元大碎裂时被源脉震荡「石化再苏醒」的一支人类，寿命长达数百年，与源脉共生。他们是唯一能在不触发灰潮的前提下接触源脉的种族，故而被各国既忌惮又需要。 | 重甲工匠、地下战、源脉锻造类职业 |
| **烬民（Ashen，兽人变体）** | 约 4%，游荡烬海 | 烬海灰潮最早的感染者后裔，已与石化共生，血液半凝固。他们是被诸国放逐的弃民，也是**灰潮真相**（神级魔法滥用的反噬）的关键证人。 | 高 HP 低魔防、狂化近战、消耗自伤换伤害的职业 |
| **源裔（Ley-born，血脉亚种）** | 约 0.01%（跨种族） | **非独立种族**，而是人类 / 精灵中体内残存第一纪元编织者血脉的极少数个体。是承载神级魔法的唯一生理基础，**各国争夺的核心「资源」**（精灵源裔尤为珍贵）。 | 神级魔法职业（卷轴持有者）的硬性前置 |

> 精灵族的叙事落点（参考：environmental-storytelling-technique + synergy-thematic-design）：精灵奴隶市场、神权国的「净灵」祭祀场（活取水晶）、流亡精灵的隐匿村落——这些都是可落地图的环境叙事点，玩家通过场景即可感知这一压迫结构的残酷，无需大段文字倾倒。精灵同伴的「水晶」既是其力量之源，也是悬在其头顶的死亡条件（见 [04 角色](04_characters.md) 精灵同伴卡）。

## 六、宗教 / 信仰

> **信仰降级声明（落实主线约束）**：崇尚魔法 / 抵制魔法**不作为主线驱动力**，仅作各国的国家性格与文化底色。主线驱动力为**神级秘法争夺**（见第四节 4.2 与第八节核心矛盾）。信仰体系仅保留神权国一支，作为中期反派的意识形态。

### 信仰：《新世典》（The Book of the New Dawn）

- **核心教义**：表面提倡**自由、平等、博爱**，宣称「新世界即将降临，众生皆平等」；实则是一套**固化社会结构、洗脑民众**的教条体系——教廷高层垄断权力，民众被规训为「等待新世界」的顺从者。
- **盛行国**：神权国（中期反派国，见 [国家设定](02_nations.md)），国教即国法。
- **扭曲祭祀**：教廷定期举办名为「净世祭」的公开仪式——以「净化魔法偷窃者」为名，当众活取精灵的额头魔法水晶，宣称「归还魔力于天地」。**真实目的**是为教廷高层（多为隐藏的源裔 / 卷轴觊觎者）收集水晶，用于承载 / 强化神级秘法。民众在洗脑下将此视为神圣。
- **对精灵的态度**：视精灵为「魔法的偷窃者」「堕落的异端」，是必须消灭的对象——这是神权国奴役 / 屠戮精灵的意识形态遮羞布。
- **战旗映射**：神权国部队多为「祭司 - 法师」复合单位（普通魔法治疗 + 伤害双修），并以「审判官」单位专门克制精灵系敌人（对精灵特攻）。神级秘法层面，神权国暗中搜集卷轴与水晶，是中期主线反派。

> 信仰在新设定下的定位（参考：synergy-thematic-design 主题协同）：《新世典》是「自以为正义的恶」——它不是黑白分明的邪教，而是一套**真诚相信自己代表光明、实则在固化压迫与收割精灵**的教条体系。这让神权国首领作为中期反派具有悲剧性的自洽，而非脸谱化。

> 两教的冲突不是善恶之争，而是「善用魔法 vs 消灭魔法」的灰色对立——两边都有道理，两边都在用极端手段。这确保玩家在剧情分支中无论选哪边都会有道德代价（参考：synergy-thematic-design 主题协同——主题「战争没有赢家」要求没有绝对正义的一方）。

## 七、科技 / 文明水平

> 明确边界，防止设定滑坡。这直接约束 `items.json` 与 `professions.json` 的武器装备范围。

| 维度 | 水平 | 禁止项（硬边界） |
|------|------|------------------|
| 冶金 | 中世纪晚期，能炼钢，黑铁帝国可铸板甲 | 无高炉炼钢、无合金钢 |
| 武器 | 冷兵器：剑、枪、斧、弓、弩、投石、攻城弩 | **无火药、无火铳、无大炮** |
| 动力 | 人力、畜力、水力、风力 | **无蒸汽机、无内燃机** |
| 工程 | 石砌城堡、要塞、攻城塔、云梯 | 无近代工事 |
| 航海 | 帆船、桨帆船，近海与内河航运 | 无远洋舰、无蒸汽船 |
| 通讯 | 信使、烽火、源脉共鸣（极稀有魔法通讯） | 无电报 |
| 医疗 | 草药、放血、普通魔法治疗（牧师常规技能） | 无近代医学 |
| 魔法科技（普通） | 元素之力驱动的民用魔导器：照明的魔晶灯、通讯的共鸣石、魔导农具等已**部分普及**于富庶城邦 | 不能造近代工业级机械（魔导炮、魔导机甲之类仍是禁止项） |
| 魔法科技（神级） | 源晶驱动的稀有法器、封印阵、源脉锻造——**极稀缺，不可量产** | 神级魔法科技不可复制、不可量产，仍属「稀有王牌」 |

> 边界说明：**普通魔法**已是民用与军事的常规力量（魔导灯、魔导农具、法师团），不再「弥补不了科技缺口」；但**神级魔法（源脉秘法）**仍极稀缺，无法成为工业级力量。这保证战旗战场是「冷兵器 + 普通法师团 + 极稀有神级王牌」的格局——普通魔法撑起日常，神级魔法决定国运。

## 八、核心矛盾（为什么必然爆发战争）

> 用一段话点明。

艾尔迦德的战争不是某位暴君一时兴起的野心，而是**神级秘法卷轴的存在本身**所必然引发的结构性崩塌：**一卷神级秘法，足以让持有国单方面碾压他国、打破大陆平衡**——这意味着「不拥有」就等于「随时可能被碾压」。于是各国陷入一个无法脱身的囚徒困境：**好战国**主动出击、四处搜刮卷轴，企图以集齐秘法终结乱世（其君主为求速胜甚至与恶魔交易，沦为力量的傀儡）；**神权国**以「净化异端 / 迎接新世界」为名，暗搜卷轴、屠戮精灵取水晶，企图独占神级力量；**中立 / 受侵略国**则被迫卷入，为不被吞并而不得不参战。卷轴不可复制、不可再生，每一次易主都伴随毁灭——而**灰潮**正是历次神级魔法滥用的累积反噬，无声地吞噬着这片被秘法贪欲撕碎的大陆。**每一方都认为自己是在「自保」或「救世」，而每一方的争夺都在把世界推向第二次大碎裂。这就是「战争没有赢家」的根源。**

## 九、环境叙事落点（可做战旗地图的地点）

> 世界观必须能落到地图与场景里，而非靠大段文字倾倒（参考：environmental-storytelling-technique——把世界当作角色，用环境元素承载叙事）。每个地点说明它天然适合什么关卡类型。

| # | 地点名 | 地点描述（环境叙事） | 适合关卡类型 |
|---|--------|----------------------|--------------|
| 1 | **圣城艾尔萨（Elsath, the Holy City）** | 被苍脊山脉主源脉贯穿的古城，金顶神殿下能听见地底源脉的低鸣。城墙刻满第一纪元编织者的浮雕。最后富源井之所在，谈判破裂之地。 | 攻城战 / 决战 |
| 2 | **黑铁要塞（Blackiron Hold）** | 扼守苍脊西麓隘口的巨型要塞，黑铁帝国边境门户。城墙嵌满阵亡者的断剑。 | 攻坚战 / 防守战 |
| 3 | **银泪渡口（Silver Tear Ford）** | 银泪河中游唯一可涉渡之处，两岸芦苇丛生，雾气终年不散。商队与军队必经之地。 | 伏击战 / 护卫商队 |
| 4 | **烬海石林（Ashen Pillars）** | 烬海中由灰潮感染者石化后形成的巨型石柱群，风蚀出无数诡异空洞。源城废墟散布其间。 | 探索 / 撤退战 / 稀有道具获取 |
| 5 | **回声深渊·矮人故都（Echoing Deep - Old Hold）** | 苍脊之下的地下城，源脉离地表最近处，岩族的最后据点。钟乳石与熔岩河交错。 | 地下战 / 限时生存 |

| 7 | **霜落祭坛（Frostfall Altar）** | 霜落荒原冰原深处的远古源井遗迹，被冰封的源井旁，矗立着无数被历代神级魔法滥用反噬而石化的源裔冰雕——他们是承载神级秘法的牺牲品。 | 夜战 / 暗杀 / 护送逃亡源裔 |
