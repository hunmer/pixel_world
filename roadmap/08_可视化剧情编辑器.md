# 08 · 可视化剧情编辑器（用户自定义剧情的核心工具）

【功能】
图形化剧情编辑器：节点图（GraphEdit）拖拽编辑对话/选项/触发事件，实时预览，导出 JSON —— 让玩家不用手写 JSON 就能做自己的剧情。

【难度】★★★★☆（中等偏难）

【详细描述】
- Godot 4 `GraphEdit` + `GraphNode` 搭建节点图：节点类型 = 对话 / 选项 / 播放音效 / 触发战斗 / 设置旗标 / 条件分支（读旗标）。拖线 = `next` 指针，天然可视化 JSON 结构。
- 新增 `scenes/StoryEditor.tscn` + `scripts/editor/story_editor.gd`，入口放 Title（「剧情工坊」），与战场地图编辑器并列。
- 双向同步：GraphEdit 图 ↔ 05 的剧本 JSON，保存时校验（孤立节点、缺失 speaker、非法跳转——复用 05 的校验器）。
- 实时预览：侧栏「试演」按钮在编辑器内嵌弹窗里直接跑 `dialogue_runner.gd`，所见即所得。
- 人物/立绘选择下拉框读 `data/story_characters.json`；文本框支持变量占位 `{player_name}`、旗标插值。
- 保存到 `user://stories/`，主菜单「自定义剧情」列表可加载游玩 —— 自定义剧情闭环就此打通。
- 与 04 呼应：剧情编辑器里可嵌入「战场引用」节点（选已有自定义地图 + 配置初始元素氛围），剧情与地图在编辑器层就完成拼装。
- 验证：契约测试覆盖图→JSON 导出正确性、JSON→图导入还原、坏图校验拒绝。
