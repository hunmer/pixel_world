# 14 · 战斗演出升级：遭遇转场与回合打击演出

【功能】
把现有「就地结算式」战斗升级为八方旅人式完整演出链：遭遇转场（遇敌瞬间画面扭曲→切入战斗场景）→ 开战对峙（敌我双方斜两侧站位、名牌逐个亮出）→ 回合打击演出（攻击者踏步上前→挥击/释放特效→受击者后仰/击退→飘字）→ 胜利结算演出。

【难度】★★★★★（困难）

【详细描述】

## 现状差距（为什么缺）
- 现有战斗是 `battle.gd` 直接在世界地图棋盘上结算：`turn_director.gd` 只做 `_tween_move` 位移 + `battle_ui.gd` 飘字/横幅，攻击命中瞬间跳变、无动作、无镜头反应 —— 逻辑对但「没有戏剧感」。

## 一、遭遇转场（Encounter Transition）
- 遇敌瞬间播放 0.5–1s 转场：屏幕径向扭曲 shader（`shaders/` 新增 `encounter_warp.gdshader`）+ 画面闪烁两下 + 音效，然后 B1 就地战斗可直接在原棋盘加「聚光灯变暗」滤镜进入战斗态；B2 切场景时转场覆盖在场景切换之上。
- 全部封装为 `scripts/battle/encounter_transition.gd`，信号驱动：`EncounterStart → (anim) → BattleReady`，不侵入 `main.gd`（B1 遵守 `_battle_active:` 前置短路纪律）。

## 二、开战对峙站位（Face-off）
- 开战时敌我单位从棋盘位置「滑入」对峙阵型：我方左下斜线、敌方右上斜线（等距视角下呈对角线对峙，八方旅人构图），镜头从俯视棋盘角度插值拉到侧向平视对峙角度（**遵守 4 正交角度约束：只做 0/90/180/270 之间的固定角度切换 + 距离/高度插值，绝不放开连续角度**）。
- 名牌演出：双方单位名牌逐个亮出（间隔 0.15s，带音效），Boss 战追加 Boss 横幅（复用 11 项设计）。
- 对峙阵型是**演出层概念**：逻辑上单位仍在棋盘原格，`battlefield_renderer.gd` 不动；新建 `battle_presentation.gd` 只操作 `UnitSprite3D` 的显示偏移，回合开始再滑回真实格位（战斗中返回棋盘视角正常行动）。

## 三、回合打击演出（核心）
- 攻击动作序列器 `scripts/battle/action_anim.gd`：把一次攻击拆成标准时间轴 ——
  1. 前摇（0.15s 蓄力：攻击者 sprite 缩放/下沉 + 武器抬升）
  2. 踏步（向目标方向位移半格并弹回）
  3. 打击帧（命中判定显示：挥砍弧光 / 元素弹道投射物——弹道飞行期间目标标记高亮）
  4. 受击反应（受击者白闪 + 后仰 0.1s + 击退效果；弱点命中追加盾裂特效与顿帧 0.08s hitstop）
  5. 飘字结算（现有 `float_text` 升级：伤害数字弹跳 + 元素配色，复用 01 元素系统）
- 动作期间**逻辑已结算、演出在回放**：`scripts/systems/` 结算先行产出 `AttackEvent`（伤害/击退/状态数据），演出层只是把事件演出来 —— 保持 headless 可测，也是 autoplay-hosting（自动战斗托管）能快进演出的前提：`turn_director.gd` 托管模式下按 `anim_speed` 倍速或直接跳过时间轴。
- 技能差异化：`data/skills.json` 加可选 `anim` 字段（`slash / projectile:arrow / burst:fire / beam` 等模板名），特效模板化复用，新技能配个字段就有演出。

## 四、镜头与节奏
- 打击镜头反应：命中瞬间轻微推近 + 顿帧；克制命中（元素相克）镜头更近 + 白边闪光 —— 「克制打击感」是八方旅人爽感的核心。
- 回合节奏：敌方回合演出加速（同托管逻辑），我方回合全速；演出总长预算普通攻击 ≤ 1.2s、技能 ≤ 2s，超预算会毁掉回合制手感。

## 五、胜利/失败结算演出
- 胜利：存活单位跳跃欢呼 + 战利品列表逐条弹出 + EXP/金币滚动数字；失败：画面褪色 + 单位倒地 sprite 替换 + 回合标题返回。
- 章节末战斗（07）追加结算标题卡。

## 实施顺序建议
转场 → 对峙站位 → 打击时间轴（先普通攻击，后技能模板）→ 镜头反应 → 结算演出。每一层都可独立上线，逐步替换现有瞬发结算。

## 验证
- 逻辑层（AttackEvent 产出）走契约测试 headless 断言；演出层用 `runtime_assert_*` 验证时间轴节点触发与结束信号；托管模式（autoplay-hosting）验证倍速/跳过路径不卡死。
- 演出素材先用现有 `meowa_tiles` + 程序化特效（弧光/弹道用 Line2D/CPUParticles3D），不阻塞在美术。
