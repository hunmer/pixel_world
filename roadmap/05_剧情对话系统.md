# 05 · 剧情对话系统（div 式可自定义剧情的展示层）

【功能】
对话剧情系统：立绘/头像 + 打字机文本 + 选项分支 + 说话人名牌，剧本完全 JSON 配置 —— 这是「可自定义 div 剧情」的运行时基础。

【难度】★★★☆☆（中等偏易）

【详细描述】
- 新增 `scripts/story/dialogue_box.gd`（UI 控件）+ `scripts/story/dialogue_runner.gd`（纯逻辑剧本解释器）。
- 剧本格式 `data/stories/*.json`（用户后期放 `user://stories/`）：
  ```json
  { "id": "ch1_open", "nodes": [
    { "id": "n1", "speaker": "阿尔夫", "portrait": "alf", "text": "……", "next": "n2" },
    { "id": "n2", "choices": [ {"text": "接下委托", "next": "n3"}, {"text": "拒绝", "next": "n4"} ] }
  ]}
  ```
- 「div 剧情自定义」的含义：剧情 = 结构化 JSON（像网页 div 一样可拼装），配合 08 的可视化编辑器让用户拖拽编辑，无需写代码。
- 功能点：打字机效果（可按键跳过）、历史记录回看、选项分支跳转、背景/音效触发钩子（`fx` 字段调 `world_audio_system.gd`）、对话结束信号 `DialogueFinished(story_id, choice_path)` 供关卡系统衔接战斗。
- 人物表：`data/story_characters.json`（名字、立绘路径、名牌颜色），立绘先用现有 `meowa_tiles` / `assets` 占位。
- 验证：契约测试覆盖节点遍历、分支选择、坏引用（指向不存在节点）报错。
