# 13 · HD-2D 表现层升级（八方旅人观感终极形态）

【功能】
把现有像素世界渲染升级为真正的八方旅人式 HD-2D 观感：景深虚化、体积感光照、粒子氛围、战斗镜头演出，使自定义内容「看起来像商业作品」。

【难度】★★★★★（困难 · 长期）

【详细描述】
- 现有基础：GL Compatibility 渲染器 + 3D 正交柱地形 + 已有 depth_of_field_system / sunlight_system / firefly / weather —— 本项是「调优与补全」而非重写。
- 景深分级：按战场层级（前景格 / 单位层 / 远景层）分 DOF 焦平面，战斗镜头拉近时自动切换焦点；受限于 GL Compatibility（无高级体积雾），用多层半透明渐变网格模拟远景雾。
- 光照氛围：昼夜已存在，补「战斗时刻光照预设」—— Boss 战切换黄昏/月光 + 定向光角度微调（`sunlight_system.gd` 加 preset 接口），遵守确定性契约（预设是内容 ID）。
- 元素特效配套（呼应 01/03）：各元素的命中粒子/地面残留（燃烧草地的火焰贴图动画、冰面的高光反射、雷击的瞬时光爆）—— 走独立特效模块 + 配置表，绝不加 `main.gd` 分支。
- 粒子氛围包：飘落花瓣/尘埃/水面反光粒子（CPUParticles3D，GL 兼容），挂相机前作屏幕空间氛围层，随 biome 自动切换（走 biome 模块 + `config/ecology/`）。
- 战斗演出镜头：回合开始 / Boss 登场 / 破盾时相机脚本化推拉摇移（时间轴数据驱动 `cutscene_camera.json`），4 正交角度约束内做插值。
- UI 质感：对话框/标题卡套 HD-2D 风格描边框 + 微噪声 + 字体分级（标题衬线/正文像素体）。
- 性能护栏：所有效果可开关（Settings 加「画面等级」档位），低档位关闭粒子与 DOF，保 60fps。
- 验证：画面效果人工验收（截图对比存 `docs/`），逻辑接口用 `runtime_assert_*` 验证；性能用帧率日志对比三档位。
