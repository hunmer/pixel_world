# 04 · 地图编辑器扩展：地形属性与交互标记

【功能】
战场编辑器（按 E）支持「自定义地图自带战术」：给区域画元素氛围（雷云区/火山区）、放置环境物件（火把、炸药桶、机关）、配置每个战场的地形效果微调 —— 让用户做出的地图不只是摆格子。

【难度】★★★☆☆（中等）

【详细描述】
- 扩展 `scripts/editor/` 现有画笔系统，新增三类工具：
  - **元素氛围刷**：给区域叠加 `element_zone`（如雷云：区域内雷伤 +30%，每回合随机劈雷——概率用战场确定性 RNG）。
  - **环境物件**：可放置/可破坏的物件（炸药桶：火系攻击引爆范围伤害；冰晶：被冰系命中生成冰面）—— 物件定义进 `data/env_objects/*.json`，行为绑定 03 的交互表。
  - **地形效果覆写**：区域级覆写 `terrain_effects`（如把某片浅水的减速改成加速「浅滩航道」），覆盖层写进战场 JSON 的 `overrides` 字段。
- 校验：保存时校验物件引用的交互键存在于 03 的交互表（引用悬空则拒绝），沿用现有「保存即校验入列」机制。
- UI：画笔面板加页签；物件放置时显示 03 交互的触发提示（放炸药桶旁显示火把图标警示）。
- 兼容：旧 JSON 战场无新字段照常加载（字段缺省跳过），`battlefield_loader.gd` 只做解析不改 schema 核心契约。
- 验证：契约测试覆盖三画笔的存取 roundtrip、覆写优先级（区域覆写 > 全局配置）、悬空引用拒绝。
