# 06 · 关卡事件系统（剧情 ↔ 战斗 ↔ 地图 串联）

【功能】
事件触发器系统：进入某区域触发对话、对话选项决定战场地图与增援、战斗胜利推进章节 —— 把「剧情、地图、战棋」串成完整关卡流程。

【难度】★★★☆☆（中等）

【详细描述】
- 关卡文件 `data/levels/*.json`：`{ "map": "battlefield_03", "events": [ {"trigger": {"type":"enter_region","cells":[[3,4]]}, "actions":[{"type":"dialogue","story":"ch1_b"}]}, {"trigger":{"type":"unit_dead","unit":"boss_scout"}, "actions":[{"type":"battle","battlefield":"boss_gate"},{"type":"set_flag","key":"gate_open","value":true}]} ] }`。
- 新增 `scripts/story/event_system.gd`：每 tick 检查触发器（enter_region / unit_dead / dialogue_choice / turn_count / timer），动作（dialogue / battle / spawn_reinforcement / set_flag / give_item / apply_element_zone）。
- 全局旗标 `flags`（字典）跨事件读写，为 10 的剧情分支打基础；旗标键名即契约。
- 战斗衔接：关卡内多段战斗（剧情→战棋→剧情→Boss），复用 B2 场景切换与 `SceneArgs` 传参；增援动作直接复用现有战场 JSON 的角色配置。
- 与元素系统联动：动作 `apply_element_zone` 可让剧情改变战场（剧情事件点燃森林 → 战场地图草地区域预置燃烧状态），剧情影响战术。
- 事件编辑器 UI 暂不做（那是 08），本项只做运行时 + JSON 手写验证。
- 验证：契约测试覆盖触发器判定顺序、旗标读写、对话→战斗→回到关卡探索的完整链路（headless 模拟）。
