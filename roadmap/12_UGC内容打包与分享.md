# 12 · UGC 内容打包与分享（创意工坊形态）

【功能】
把自定义剧情 + 自定义地图 + 章节编排打包成单个「剧本包」文件，一键导入分享 —— 完成「可自定义」从单件内容到整包作品的跃迁。

【难度】★★★★★（困难）

【详细描述】
- 打包器 `scripts/core/pack_system.gd`：把 `user://stories/` + `user://battlefields/` + 关卡/章节 JSON + 用户素材清单，用 PCK（Godot 原生）或 zip 打成单文件，附 `manifest.json`（包名、作者、版本、内容 ID 清单、sha256）。
- 内容 ID 冲突治理：包内 ID 命名空间化（`pkg_ch1/battlefield_xxx`），加载时与本体及已装包做冲突检测 —— 全项目最难的部分，牵动确定性契约；建议发布第一个包起就锁定 ID 生成规则（哈希前缀）。
- 元素/地形内容扩展点：包内可携带自定义交互表条目（新增元素组合）与新地形效果覆写，manifest 声明依赖的本体元素枚举（引用不存在的元素则拒绝）。
- 导入流程：主菜单「内容包管理」→ 选择文件 → 校验 manifest / 依赖（引用了本体没有的技能/职业/元素则拒绝并列出缺失）→ 落盘 `user://packages/` → 注册进「自定义剧情/地图」列表。
- 素材边界：第一版只允许复用本体已有素材（贴图/音效白名单清单），杜绝任意文件注入；自选素材留到后期 + 大小/格式白名单限制。
- 章节编排器：08 剧情编辑器基础上加「章节编排」页签（把已有剧情/地图/战斗拖成章节序列），让玩家能做出完整的小型作品。
- 验证：契约测试覆盖打包 roundtrip、ID 冲突拒绝、依赖缺失拒绝、损坏包（sha 不符）拒绝。
