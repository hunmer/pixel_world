# 02 · 地形效果系统（站立增益/减益）

【功能】
给战棋 11 种地形附加战术效果：站在不同地形上的单位获得命中/闪避/防御/移动力修正或每回合状态（如浅水减速、高台命中加成），让走位产生八方旅人式策略深度。

【难度】★★☆☆☆（简单）

【详细描述】
- 新增 `config/terrain_effects.json`，按现有地形 ID 配置：`{ "shallow_water": {"move_cost": 2, "evasion": -10, "status_per_turn": null}, "highland": {"hit_bonus": 15, "defense": +2} }`（字段缺省 = 无效果，完全向后兼容现有战场 JSON）。
- 新增 `scripts/core/terrain_effects.gd` 纯逻辑模块：`get_effect(terrain_id) -> TerrainEffect`，战斗结算与寻路统一从它读，禁止散落 if。
- 寻路接入：`move_cost` 参与现有寻路代价（浅水/密林走起来更贵），UI 在悬停格子时 tooltip 显示地形效果。
- 视觉反馈：单位站在效果地形上脚底加小图标环（复用 `scripts/iso/battlefield_renderer.gd` 的挂点），不新增渲染管线。
- 命中/闪避/防御修正进入 `scripts/systems/` 结算乘区（与 01 的元素乘区并列，顺序固定：地形 → 元素 → 暴击）。
- 验证：`tests/terrain_effects_contract.gd` 覆盖配置解析、缺省兼容、寻路代价变化、结算顺序。
