# 15 · 战棋 UI 清单

【功能】
战棋游戏常见 UI 元素全景清单：标注每项的【现状】（已有 / 需升级 / 缺失）、内容描述与实现建议，作为战斗 UI 迭代的对照清单。

【难度】★★★☆☆（中等偏易 · 逐项可拆）

【详细描述】

## 一、战斗信息层（HUD 常驻）

| UI | 描述 | 现状 |
| --- | --- | --- |
| 回合指示条 | 当前阵营（我方/敌方）+ 回合数，切阵营时横幅扫过 | 部分（`set_phase_text` 纯文本，缺扫屏横幅） |
| 顶栏资源条 | 金币、回合上限（限时关卡）、天气/元素氛围图标 | 缺失 |
| 小地图 | 战场缩略图 + 敌我点位闪烁，点击跳转镜头 | 缺失 |
| 行动顺序轴（Time Line） | 本回合及下回合行动顺序头像队列，插在轴中央（FFT/NG 式），是战棋 UI 的灵魂组件 | 缺失 |
| 危险区域提示 | 敌方威胁范围红色叠层 / 我方可达范围蓝色叠层（开关切换） | 部分（`range_overlay.gd` 有范围，缺敌方威胁合成层） |

## 实施建议
- 优先补齐「行动顺序轴」「危险区域合成层」「预测伤害乘区明细」「Undo」四项——它们直接决定战棋手感，且全是 Control 层工作，不动逻辑。
- 所有 UI 数据源走 `scripts/systems/` 纯逻辑的查询接口，UI 层禁止自己算伤害/范围（保持 headless 可测）。
- 风格统一：HD-2D 描边框（13 项）+ 元素配色体系（01 项）作为全局 UI 主题。
