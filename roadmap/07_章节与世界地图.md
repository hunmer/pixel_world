# 07 · 八方旅人式章节推进与世界地图

【功能】
章节化主线：世界地图上选章节节点 → 过场剧情 → 战棋关卡 → 章节结算（奖励/解锁下一章），呈现八方旅人「八个主角八个篇章」的结构感。

【难度】★★★☆☆（中等）

【详细描述】
- 章节表 `data/chapters/*.json`：`{ "id":"ch1", "title":"第一章·风之谷", "levels":["ch1_l1","ch1_l2"], "next":"ch2", "rewards":{...} }` —— 章节顺序是内容 ID 契约，定稿后不可重排。
- 世界地图 UI：新建 `scenes/WorldMap.tscn`（复用 `scripts/world_map_overlay.gd` 或 `side_panel.gd` 的风格），章节节点 = 已通关（绿）/当前（金）/未解锁（灰）。视角旋转、镜头推拉演出参考现有 `isometric_view.gd` 的 4 正交角度约定。
- 章节流程状态机：`map → dialogue → battle → (loop) → chapter_clear → rewards → next_chapter`，由 06 的事件系统驱动，只新增一个顶层 `ChapterDirector` autoload。
- 与元素/地形系统叙事联动：每个章节主题绑定一个元素（火焰山谷主火系地形交互、雷雨湖泽主雷水交互），章节教学演出引导玩家发现 03 的招牌组合 —— 机制即叙事。
- 主菜单（Title.tscn）加「新的旅程 / 继续旅程」入口，为 09 存档做入口铺垫（本项先做内存态进度）。
- 演出感：章节开场加标题卡（大字标题 + 淡入淡出 + 一句引言），成本极低但八方味最浓。
- 验证：契约测试覆盖章节解锁顺序、非法跳章拒绝、奖励发放。
