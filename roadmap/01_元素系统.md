# 01 · 元素系统（属性与相克）

【功能】
给技能/武器/单位引入元素属性（火/水/雷/冰/风/土/光/暗），建立相克表：克制加伤、被抗减伤，纯数据驱动。

【难度】★★☆☆☆（简单）

【详细描述】
- 新增 `scripts/core/elements.gd`：枚举 + 相克矩阵 + 单点结算函数 `elemental_multiplier(atk_elem, def_elem) -> float`（克制 1.5 / 被克 0.5 / 无关系 1.0，数值进 `config/elements.json` 可调）。
- 相克表参考经典设定：火→冰→风→土→雷→水→火（环），光↔暗互克；后续可调。
- 数据接入：`data/skills.json` 每条技能加 `element` 字段（缺省 `"none"` 物理无属性）；`professions.json` 可给职业加 `resist_elements` / `weak_elements`（八方旅人式「敌人有明确弱点」体验的根基）。
- 战斗结算挂点：在 `scripts/systems/` 现有伤害计算处插入元素乘区，UI 伤害飘字变色（火红/水蓝/雷紫）+ 「弱点命中!」标记。
- 约束：`element` 字段是内容 ID 契约，定稿后不可重命名；相克数值改动不影响存档（存档只引用元素枚举名）。
- 验证：新增 `tests/elements_contract.gd`，覆盖相克矩阵完整性（每种元素至少一克一被克）、倍率计算、技能缺省字段兼容旧 JSON。
