# 技能图标进化表：网页版提示词与技能列表

## 一、网页版设置

| 项 | 像素风（推荐） | 手绘发光风 |
| --- | --- | --- |
| 模型 | **Lib Image 2.6 Pro** | Seedream 5.5 |
| 比例 | **2:1**（正好排 10×5） | 21:9（没有 2:1；16:9 排不下 10 列） |
| 清晰度 / 画质 | 2K / 高画质 | 2K |
| 输出格式 | PNG | — |
| 背景 | 保留背景 | 保留背景 |
| 参考图 | 上传 1 张风格参考，在提示词里用 **@** 引用 | 同左 |

**参考图怎么选：**
- 新分类：上传一张已经满意的像素表（比如 `pixel_fire_sheet_10x5_128.png`）当**风格参考**，用下面的「模板 A」。
- 已有手绘表、想转成像素风：上传该分类规整后的 1280×640 表（`<分类>_sheet_10x5_128.png`），用「模板 B」。
- **注意：** 不要用原始手绘大图当参考，它的最后一列偏宽，新图会照搬。

> [!TIP]
> 每次生成 2~4 张挑一张。最常见的问题是某一行少一格或多一格，再生成一次通常就好。

## 二、提示词模板

使用方法：复制模板，替换 `【分类名】`、`【色系】` 和五行内容（从第三节挑），`@参考图` 换成网页里 @ 出来的那张图。

### 模板 A：新分类，像素风（参考已有像素表的风格）

```text
参考 @参考图 的像素画风格和网格排版，生成一张全新的「【分类名】系」复古像素风（pixel art）游戏技能图标表。
严格 10 列 × 5 行网格，共 50 个图标，每一行恰好 10 个、每一列恰好 5 个，所有格子大小相同、严格对齐，格与格之间留出均匀的纯黑细间隔，每个图标是独立完整的方形，主体不超出格子。
像素风要求：每个图标相当于 32×32 像素的低分辨率像素画等比放大，像素块清晰方正、硬边、无抗锯齿、无模糊、无渐变柔光，使用有限调色板（每个图标约 12~16 色），主体有 1 像素深色描边，光晕和发光用像素抖动（dithering）与阶梯色块表现，近黑色深色背景，类似 16-bit SNES/GBA 时代 RPG 的技能图标。
每一行是一条技能进化线：第 1~3 列初级，像素图形简单、体积小、颜色少；第 4~7 列中级，细节与粒子增多；第 8~10 列高级到顶级，体积大、色彩丰富、加入金色与白色高光像素，第 10 列最华丽。同一行内是同一主题的连续进化，相邻图标差异清晰可辨。
五行分别为：第 1 行「【第1行】」；第 2 行「【第2行】」；第 3 行「【第3行】」；第 4 行「【第4行】」；第 5 行「【第5行】」。
整张统一【色系】色系。画面中绝对不要出现任何文字、数字、编号或角标，不要边框装饰、不要网格线、不要底座。
```

## 四、常见问题

| 问题 | 解决 |
| --- | --- |
| 某行只有 9 个或 11 个 | 再生成一次；或在提示词开头加「**每一行必须恰好 10 个图标，共 10 列**」 |
| 出现数字编号 | 已有「绝对不要出现任何文字、数字、编号或角标」；仍出现就换一张参考图（不要用带编号的图） |
| 最后一列特别宽 | 参考图换成规整的 1280×640 表 |
| 某个物体画错（如木盾画成木桌） | 写得更具体：「一面简陋的圆形小木盾牌……整行每格都必须是盾牌」 |
| 像素感不够、有柔光 | 加一句「不要任何柔和泛光，发光只用 2~3 级阶梯色块和像素抖动表现」 |
| 想要更粗的像素 | 把「32×32」改成「24×24」或「16×16」 |

生成后下载原图放到 `E:\pixel_world\meowa_tiles\generated\skill_icons\evo_sheets\`，用 `PIXEL_GRID=32 python slice.py <原图> pixel_<分类>` 就能切出 32px 和 128px 的图标。
